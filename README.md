# Impulso Digital

Sitio institucional de ejemplo para el parcial práctico de desarrollo colaborativo.

## Tecnologías
- HTML5
- CSS3
- JavaScript puro

No requiere instalación de dependencias ni servidor backend.

## Cómo ejecutar
1. Clonar o descargar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Abrir `index.html` en el navegador o utilizar la extensión Live Server.

## Estructura
- `index.html`: página principal.
- `equipo.html`: presentación del equipo.
- `servicios.html`: servicios ofrecidos.
- `contacto.html`: datos de contacto y formulario de demostración.
- `css/style.css`: estilos generales.
- `js/navbar.js`: navegación y pie compartidos.
- `js/main.js`: interacciones generales.
- `assets/images/`: recursos gráficos.

## Consideraciones
- El formulario es demostrativo y no envía información.
- Los perfiles y datos de contacto son ficticios.
- Los enlaces de redes sociales son ilustrativos.
- La navegación se genera desde `js/navbar.js`.

## Trabajo colaborativo
Cada integrante debe trabajar en una rama propia, realizar commits, publicar su rama y abrir un Pull Request hacia `main`. Los cambios deben ser revisados por otro integrante antes de integrarse.
